<decisions_made>

**Architecture Decisions:**
- React 19.2 over 18.x for latest features
- Tailwind CSS v4 for better Vite integration
- shadcn/ui "new-york" style for modern aesthetics
- Fixed sidebar on desktop (320px) for consistent UX
- Drawer navigation on mobile with swipe gestures
- Theme toggle in sidebar footer (desktop), will move in Phase 2

**Technical Decisions:**
- Inline styles for background colors (Tailwind v4 CSS variable compatibility)
- Custom CSS classes for button hover states (Tailwind v4 limitations)
- class-variance-authority for component variant system
- react-swipeable for gesture handling (works on desktop and mobile)
- useScrollDirection hook for auto-hiding nav (performance optimized)

**Bug Fixes:**
- Dialog background: Used `style={{ backgroundColor: 'hsl(var(--card))' }}`
- Button hover: Created `.btn-default:hover`, `.btn-destructive:hover` etc. in index.css
- Sidebar overlap: Moved Sidebar outside flex container, added proper padding
- MobileDrawer: Same inline style approach as Dialog

**CSS Patterns Established:**
```css
/* For Tailwind v4 CSS variables with transparency */
background-color: hsl(var(--card) / 0.9);
```

```tsx
/* For solid backgrounds (when Tailwind classes don't work) */
style={{ backgroundColor: 'hsl(var(--card))' }}
```
