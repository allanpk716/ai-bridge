<task type="auto">
  <name>Task 2: Configure vite-plugin-pwa</name>
  <files>web/vite.config.ts</files>
  <action>
    Add VitePWA plugin to vite.config.ts with the following configuration:

    1. Import VitePWA from 'vite-plugin-pwa'
    2. Add to plugins array after tailwindcss() and react()
    3. Configure with:
       - registerType: 'prompt' (prompt user before updating)
       - includeAssets: ['favicon.ico', 'robots.txt']
       - manifest with:
         - name: 'AI-Bridge'
         - short_name: 'AIBridge'
         - description: 'Remote access to Claude Code CLI'
         - theme_color: '#ffffff'
         - background_color: '#ffffff'
         - display: 'standalone'
         - icons: use vite.svg as source (192x192 and 512x512, purpose: 'any maskable')
       - workbox.globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'] (static only)
       - workbox.cleanupOutdatedCaches: true
       - devOptions.enabled: false (PWA only in production)

    Do NOT configure runtimeCaching - we only cache static assets per CONTEXT.md decision.
  </action>
  <verify>grep -q "VitePWA" web/vite.config.ts && grep -q "registerType.*prompt" web/vite.config.ts</verify>
  <done>VitePWA plugin is configured with manifest and workbox settings</done>
</task>

<task type="auto">
  <name>Task 4: Register Service Worker in main.tsx</name>
  <files>web/src/main.tsx</files>
  <action>
    Add Service Worker registration in main.tsx:

    1. Import registerSW from virtual:pwa-register/react (dynamic import inside PROD check)
    2. Wrap registration in import.meta.env.PROD check (only register in production)
    3. Check for 'serviceWorker' in navigator before registering
    4. Call registerSW with onOfflineReady callback logging to console
    5. Place registration before createRoot() but after imports

    Pattern from RESEARCH.md:
    ```typescript
    if (import.meta.env.PROD && 'serviceWorker' in navigator) {
      import('virtual:pwa-register/react').then(({ registerSW }) => {
        registerSW({
          onOfflineReady() {
            console.log('App ready to work offline')
          }
        })
      })
    }
    ```
  </action>
  <verify>grep -q "virtual:pwa-register/react" web/src/main.tsx && grep -q "import.meta.env.PROD" web/src/main.tsx</verify>
  <done>Service Worker registration code exists in main.tsx with PROD check</done>
</task>
