<decisions_made>
**Phase 8 关键决策：**

1. **外部上下文传递架构**
   - 决定采用 props → frontend → backend → CLI 的单向数据流
   - 使用序列化的 JSON 格式传输上下文
   - 前端提供上下文预览 UI（SVG 缩略图、JSON 树、文件引用卡片）
   - 后端将上下文转换为 Claude 可理解的格式并注入到消息流

2. **多租户隔离**
   - 后端使用 application ID 进行会话隔离
   - 每个外部应用可以运行多个并发 Claude 实例
   - 防止不同应用/会话之间的上下文污染

3. **集成模式**
   - Go SDK：外部 Go 应用可以作为库导入 AI-Bridge
   - React 组件库：外部 Web 应用可以嵌入 AI-Bridge 的 UI 组件
   - 支持上下文注入：初始提示词、项目元数据、自定义工具、SVG 元素等

**Phase 5 PWA 实现方式：**
- 使用 vite-plugin-pwa 简化 Service Worker 配置
- 采用浏览器默认安装提示（非自定义 UI）
- 离线时进入只读模式，禁用发送消息功能
</decisions_made>
