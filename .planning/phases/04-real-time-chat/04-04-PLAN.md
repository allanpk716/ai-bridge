<objective>
Implement incremental message sync using SSE (Server-Sent Events) for real-time updates and pagination for historical scroll. This enables the chat interface to receive new messages instantly and load older messages on demand without fetching entire history.

Purpose: 10,000+ message sessions cannot fetch full history on each load. SSE provides incremental updates via `since` parameter, and `before` parameter enables historical scroll. This is the core performance optimization from Phase 4 requirements.

Output: useSSE hook for SSE connections, useChatMessages hook for message state management, and SessionDetail integration showing real-time chat.
</objective>
