# Phase 4: Real-Time Chat - Context

**Gathered:** 2026-02-08
**Status:** Ready for planning

## Phase Boundary

实现完整的聊天界面,包括虚拟化消息列表、流式响应显示、权限请求处理和斜杠命令执行。消息通过 WebSocket 实时推送,支持 10,000+ 消息会话的性能优化。

## Implementation Decisions

### 消息列表布局
- **布局风格**: 气泡对话式 — 用户消息靠右,AI 消息靠左,气泡背景区分(类似微信/WhatsApp)
- **长消息处理**: 完整显示所有内容,不折叠,适合阅读长文本
- **元数据显示**: 悬停显示工具栏,包含时间戳、模型图标(Haiku/Sonnet/Opus)、序号、复制等操作
- **代码块样式**: 卡片式代码块 — 深色背景容器,顶部显示语言标签,右上角复制按钮,语法高亮

### 流式响应表现
- **流式效果**: 逐字追加 — 每个 token 到达立即追加到 DOM,类似 ChatGPT 的打字机效果
- **流式指示器**: 显示光标动画 — 流式过程中显示动画光标或三个跳动的圆点
- **错误处理**: 显示错误卡片 — 流式过程中断时,在消息位置显示错误提示+重试按钮
- **停止生成**: 显示停止按钮 — 流式过程中消息上方显示「停止生成」按钮

### 权限请求交互
- **弹窗时机**: 嵌入式卡片 — 消息流中显示权限请求卡片,非阻塞,用户可选择或忽略
- **权限信息**: 精简+可展开 — 操作类型+文件路径,命令内容折叠可展开查看详情
- **作用域选择**: 多选复选框 — 用户可选择特定文件或「全部允许」
- **历史权限**: 显示历史状态 — 已批准/拒绝的权限请求在消息列表中显示状态,不可再次操作

### 斜杠命令体验
- **命令触发**: 两者都支持 — 「/」触发快速命令面板,工具栏按钮提供完整浏览
- **自定义命令**: 支持用户自定义的斜杠命令(内置/用户/项目三个来源)
- **命令搜索**: 模糊搜索 — 输入时实时过滤命令列表,支持命令名和描述的模糊匹配
- **命令分类**: 徽章标记 — 单列表显示所有命令,命令卡片显示类别徽章(builtin/user/project)
- **命令执行**: 填充到输入框 — 选择命令后先填充到输入框,用户可编辑参数后手动发送

### Claude's Discretion

- 光标动画的具体实现(跳动的圆点、闪烁的光标等)
- 错误卡片的具体文案和样式

- 代码块语法高亮库的选择

## Specific Ideas

参考产品的交互模式:
- ChatGPT 的打字机流式效果
- 微信/WhatsApp 的气泡对话布局
- VSCode 命令面板 (Ctrl+Shift+P) 的搜索体验

性能要求:
- 10,000+ 消息会话需要虚拟化滚动
- 流式响应不能阻塞 UI 线程
- 增量同步使用 since/before 分页参数
