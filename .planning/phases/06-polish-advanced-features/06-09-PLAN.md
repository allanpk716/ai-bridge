## Tasks

### Task 1: 扩展 Message 类型定义

**问题**: `SessionDetail.tsx` 使用 Message 类型,但当前定义缺少 `id`, `sessionId`, `createdAt` 字段。

**当前定义** (`pkg/protocol/types.go`):
```go
type MessageSchema struct {
    Seq       int64  `json:"seq"`
    Role      string `json:"role"`
    Content   string `json:"content"`
    Timestamp string `json:"timestamp"`
}
```

**扩展为**:
```go
type MessageSchema struct {
    Seq        int64  `json:"seq"`
    ID         string `json:"id,omitempty"`         // NEW: Message unique ID
    SessionID  string `json:"sessionId,omitempty"`  // NEW: Parent session ID
    Role       string `json:"role"`
    Content    string `json:"content"`
    Timestamp  string `json:"timestamp"`
    CreatedAt  string `json:"createdAt,omitempty"`  // NEW: ISO creation time
}
```

**同步到前端** (`web/src/types/api.ts`):
```typescript
export interface Message {
  seq: number;
  id?: string;
  sessionId?: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp: string;
  createdAt?: string;
}
```

**Verify**: TypeScript 编译不再报错 Message 类型缺失字段

### Task 2: 修复 WebSocket hooks 类型问题

**文件**: `web/src/lib/socket/hooks.ts`

**问题**: `ServerToClientEvents[K]` 类型不兼容事件监听器签名

**当前代码**:
```typescript
const handleEvent = <K extends keyof ServerToClientEvents>(
  event: K,
  handler: ServerToClientEvents[K]
) => {
  socket.on(event, handler as any); // 使用 as any 绕过类型检查
};
```

**修复方案 1**: 使用类型断言 (临时方案)
```typescript
import type { Socket } from 'socket.io-client';

const handleEvent = <K extends keyof ServerToClientEvents>(
  event: K,
  handler: ServerToClientEvents[K]
) => {
  socket.on(event, handler as (...args: any[]) => void);
};
```

**修复方案 2**: 扩展事件类型定义
```typescript
// src/lib/socket/types.ts
export interface ServerToClientEvents {
  message: (data: Message) => void;
  message_update: (seq: number, content: string) => void;
  // ... other events
}

export type SocketEventHandler<K extends keyof ServerToClientEvents> = (
  ...args: Parameters<ServerToClientEvents[K]>
) => void;
```

**Verify**: `tsc --noEmit` 不再报告 socket hooks 类型错误
