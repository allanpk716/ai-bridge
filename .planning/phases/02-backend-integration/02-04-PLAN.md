<objective>
Implement connection state management with Zustand store, visual status indicator, and user-friendly connection failure handling. Track Socket.IO connection status in real-time, display visual feedback to user, and provide recovery options when connection fails.

Purpose: Users need clear feedback about backend connectivity status. Visual indicators (colored dots + tooltips) provide immediate awareness, connection failure modal enables recovery (retry button), and automatic status tracking (via Socket.IO events) keeps UI in sync with actual connection state. Zustand is used instead of Context to avoid unnecessary re-renders (connection status updates frequently).

Output: Working connection status system with Zustand store, status indicator components in TopNav/Sidebar, connection manager integrating Socket.IO events, and connection failure dialog with retry functionality.

       ```typescript
       import { create } from 'zustand'

       export type ConnectionStatus = 'online' | 'offline' | 'reconnecting' | 'error'

       interface ConnectionStore {
         status: ConnectionStatus
         setStatus: (status: ConnectionStatus) => void
         reset: () => void
       }

       export const useConnectionStore = create<ConnectionStore>((set) => ({
         status: 'offline',
         setStatus: (status) => set({ status }),
         reset: () => set({ status: 'offline' }),
       }))
       ```

    DO NOT use React Context. Research confirmed Context causes all consumers to re-render on every status change, which is problematic for frequently-updating state like connection status. Zustand uses selector-based subscriptions (only components using specific state update).

    Create web/src/lib/socket/connectionManager.ts with:

    1. Import getSocket from @/lib/socket/socket
    2. Import useConnectionStore from @/lib/stores/connection
    3. Create initConnectionManager() function that:
       - Gets socket instance
       - Gets setStatus from store
       - Attaches event listeners for:
         - `connect` → setStatus('online')
         - `disconnect` → setStatus('offline')
         - `reconnect_attempt` → setStatus('reconnecting')
         - `reconnect` → setStatus('online') + log attempt count
         - `reconnect_failed` → setStatus('error')
         - `error` → setStatus('error') + log error

       ```typescript
       export function initConnectionManager() {
         const socket = getSocket()
         const setStatus = useConnectionStore.getState().setStatus

         socket.io.on('reconnect', (attemptNumber) => {
           console.log(`Reconnected after ${attemptNumber} attempts`)
           setStatus('online')
         })

         socket.io.on('reconnect_attempt', (attemptNumber) => {
           setStatus('reconnecting')
           console.log(`Reconnection attempt ${attemptNumber}`)
         })

         socket.io.on('reconnect_failed', () => {
           setStatus('error')
           console.error('Reconnection failed after 10 attempts')
         })

         socket.io.on('error', (error) => {
           console.error('Socket error:', error)
           setStatus('error')
         })

         socket.on('connect', () => {
           setStatus('online')
         })

         socket.on('disconnect', (reason) => {
           setStatus('offline')
           console.log('Disconnected:', reason)
         })
       }
       ```

    CRITICAL: Attach listeners to socket.io (Manager) for reconnection events, socket for connect/disconnect events. This is the correct Socket.IO v4 API.

    Reference RESEARCH.md > Code Examples > Socket.IO Connection Status Tracking.

    - Show Dialog when status === 'error'
    - Display error message: "Connection failed. Please check your network."
    - Provide "Retry" button (calls connectSocket())
    - Provide "Dismiss" button (closes dialog, user can manually retry later)

    ```typescript
    export function ConnectionDialog() {
      const status = useConnectionStore((state) => state.status)
      const [open, setOpen] = useState(false)

      useEffect(() => {
        setOpen(status === 'error')
      }, [status])

      const handleRetry = () => {
        connectSocket()
        setOpen(false)
      }

      return (
        <Dialog open={open} onOpenChange={setOpen}>
          <DialogContent>
            <DialogHeader>
              <DialogTitle>Connection Failed</DialogTitle>
              <DialogDescription>
                Unable to connect to backend server. Please check your network connection and try again.
              </DialogDescription>
            </DialogHeader>
            <DialogFooter>
              <Button variant="outline" onClick={() => setOpen(false)}>
                Dismiss
              </Button>
              <Button onClick={handleRetry}>
                Retry
              </Button>
            </DialogFooter>
          </DialogContent>
        </Dialog>
      )
    }
    ```

    DO NOT automatically retry. CONTEXT.md decision: show modal and let user choose.
