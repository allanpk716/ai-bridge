<decisions>
## Implementation Decisions

### 连接配置与启动
- **后端 URL 配置**: 混合方式 — 优先读取环境变量 `VITE_API_URL`,未定义时回退到默认值 `http://localhost:8080`
- **环境变量管理**:
  - `.env.local` 用于本地开发(不提交到 Git)
  - `.env.production` 用于生产构建
  - `VITE_API_URL` 为可选配置,有默认值
- **连接时机**: 应用启动时自动连接,无需用户操作
- **启动时连接失败**: 显示模态框让用户选择(重试/稍后再试/离线模式)
- **环境区分**:
  - 读取 `VITE_API_URL`,如果未定义则使用 `localhost:8080`
  - 开发/生产环境使用相同的环境变量机制
- **连接超时**: 初始连接尝试超时时间为 3 秒
- **多后端支持**: Phase 2 仅支持单一后端 URL,暂不支持多后端切换
- **API 基础路径**: `/api/v1` (完整 URL: `http://localhost:8080/api/v1/sessions`)
- **WebSocket URL**: 从 HTTP URL 自动推导(ws:// 替换 http://, wss:// 替换 https://)
- **配置持久化**: 不支持用户自定义 URL 持久化,仅使用环境变量和默认值
- **配置加载时机**: 在 main.tsx 中初始化,渲染任何组件前完成配置加载

### 连接状态展示
- **状态指示器位置**:
  - 桌面端: 顶部导航栏
  - 移动端: 侧边栏抽屉中
- **视觉样式**: 状态点设计(彩色圆点)
  - 在线: 绿色
  - 离线: 灰色
  - 重连中: 黄色(脉动动画)
  - 错误: 红色
- **状态点大小**: 中等(直径 12px)
- **详细信息**: 鼠标悬停显示 tooltip 提示详细状态
- **状态历史**: 仅显示当前状态,不显示历史记录
- **离线时行为**: 状态点变为灰色,同时禁用需要后端的功能(如发送消息)
- **状态切换动画**: 重连中状态有脉动动画效果

### 错误处理策略
- **错误展示方式**: Toast 通知(屏幕底部短暂显示)
- **错误展示范围**: 所有错误都显示提示(包括后台自动请求的失败)
- **自动重试**: 不自动重试,立即显示错误
- **重试间隔**: 如果未来启用重试,间隔为 1 秒

### Socket.IO 重连行为
- **首次重连延迟**: 连接断开后等待 1 秒首次尝试重连
- **退避策略**: 指数退避(1s, 2s, 4s, 8s...),最大延迟 30 秒
- **最大重连次数**: 10 次尝试后停止
- **重连失败后**: 显示 Toast 提示"连接失败,请检查网络",并提供手动重试按钮

### Claude's Discretion
- 状态指示器在顶部导航栏的具体位置(左侧/右侧)
- Tooltip 的具体样式和动画时长
- Toast 通知的显示时长和位置细节
- 脉动动画的具体实现(CSS vs 动画库)
- 错误消息的具体文案和语气
- 重试按钮的具体 UI 设计

</decisions>

<specifics>
## Specific Ideas

- **快速失败**: 3 秒连接超时确保用户及时知道网络问题
- **用户控制**: 连接失败时让用户决定下一步(重试/离线模式)
- **渐进式重连**: Socket.IO 使用指数退避,避免服务器压力
- **清晰反馈**: 状态点配合 tooltip 和禁用功能,用户明确知道当前状态
- **静默到显性**: 自动重连失败后才显示提示,避免打扰用户

</specifics>
