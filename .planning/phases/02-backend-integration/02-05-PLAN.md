<objective>
Implement global error handling with react-error-boundary for React component errors and Sonner toast notifications for API errors. Ensure no unhandled errors crash the application, provide user-friendly error messages, and enable error recovery.

Purpose: Applications will encounter errors (network failures, API bugs, component errors). Without error boundaries, these crash the entire app (white screen). Without toast notifications, API errors fail silently. Global error handling ensures graceful degradation, user awareness, and recovery options. This is production-ready infrastructure.

Output: Working error boundary with fallback UI, toast notification system, TanStack Query error integration, and comprehensive error coverage.
</objective>
