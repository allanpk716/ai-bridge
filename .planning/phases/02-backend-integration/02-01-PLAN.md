<task type="auto">
  <name>Create QueryProvider with QueryClient configuration</name>
  <files>web/src/providers/QueryProvider.tsx</files>
  <action>
    Create new provider file at web/src/providers/QueryProvider.tsx with:

    1. Import QueryClient, QueryClientProvider from @tanstack/react-query
    2. Import ReactQueryDevtools from @tanstack/react-query-devtools
    3. Create QueryClient instance with configuration:
       - staleTime: 1000 * 60 * 5 (5 minutes - data considered fresh)
       - gcTime: 1000 * 60 * 30 (30 minutes - garbage collection time, formerly cacheTime)
       - retry: 3 (retry failed requests 3 times)
       - retryDelay: exponential backoff (Math.min(1000 * 2 ** attemptIndex, 30000))
       - refetchOnWindowFocus: false (don't refetch on window focus)
       - refetchOnReconnect: true (refetch when network reconnects)
    4. Add QueryCache with onError callback for global error logging
    5. Export QueryProvider component wrapping children with QueryClientProvider
    6. Include ReactQueryDevtools component (only in development)

    CRITICAL: Do NOT use onSuccess/onError in useQuery - these were removed in TanStack Query v5. Use global QueryCache for logging instead.

    Reference pattern from RESEARCH.md > Pattern 1: TanStack Query Default Configuration.
  </action>
  <verify>File exists at web/src/providers/QueryProvider.tsx with QueryClient configured and QueryProvider exported</verify>
  <done>QueryProvider component exists with QueryClient having all default options configured (staleTime, gcTime, retry, QueryCache)</done>
